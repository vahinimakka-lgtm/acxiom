# AxiomCRM

Node.js + Express + SQLite implementation of the AxiomCRM assignment.

## Run

1. Install dependencies: `npm install`
2. Start the app: `npm start`
3. Open `http://localhost:3000`

## Demo Accounts

- Admin: `admin@acxiom.local` / `Admin@123`
- Manager: `manager@acxiom.local` / `Manager@123`
- Sales Executive: `sales@acxiom.local` / `Sales@123`

## Features

- Authentication with login, register, logout, lockout, and role checks
- Customers, leads, opportunities, follow-ups, activities, and user administration
- Dashboard metrics and report pages
- JSON REST API under `/api`
- Server-side validation and audit logging
